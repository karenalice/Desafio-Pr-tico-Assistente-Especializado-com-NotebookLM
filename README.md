📌 Assistente Especialista com IA (NotebookLM)

Esse projeto foi desenvolvido com o objetivo de criar um assistente de Inteligência Artificial especializado em um produto específico, utilizando engenharia de prompt e uma base de conhecimento bem estruturada.

A ideia foi ir além de apenas configurar uma IA: aqui eu pensei como alguém que está criando um produto de verdade. Primeiro, defini o produto, organizei todas as informações em um documento claro e, a partir disso, criei um assistente capaz de responder dúvidas com precisão usando o Google NotebookLM.

🚀 O que tem nesse repositório?

Basicamente, o projeto é composto por dois arquivos:

📄 Documento do Produto
Onde explico o que é o produto, como funciona e quais problemas ele resolve.
🤖 Prompt do Assistente
Aqui está toda a lógica de comportamento da IA: como ela deve responder, o que pode ou não pode fazer, e como manter respostas confiáveis.
🧠 O que foi aplicado

Durante o desenvolvimento, trabalhei com:

Técnicas de engenharia de prompt (Zero-Shot e Few-Shot)
Estruturação de produto
Criação de assistente especializado
Organização de documentação para IA
🎯 Qual é a proposta?

Criar um assistente que:

Responda como um especialista no produto
Seja claro e direto nas explicações
Use apenas o que está documentado
Não invente respostas
Saiba reconhecer quando não tem informação
💡 Diferencial

Mais do que responder perguntas, o assistente foi pensado para ajudar o usuário a entender o produto de verdade, explicando de forma simples e trazendo exemplos quando necessário.
